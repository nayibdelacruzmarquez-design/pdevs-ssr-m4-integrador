# ADR 4.1: Definición del Caso de Uso y Alcance del Sistema

* **Estatus:** Aceptado
* **Contexto:** Definición del protocolo de investigación para la aplicación web.
* **Decisión:** Implementar un portal de publicaciones ligero con dos roles de usuario.
* **Alternativas:** Sistema e-commerce completo o API REST desacoplada.
* **Consecuencias:** Alcance acotado ejecutable dentro del presupuesto de 5 horas.
* **Evidencia:** Requisitos de la entrega del Módulo 4.
